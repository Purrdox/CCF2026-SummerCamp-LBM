## 实现思路 P1-A

**文件:** `inc/2D/gpu/mrUtilFuncGpu2D.h`
**函数:** `mrUtilFuncGpu2D::mlCalDistributionD2Q9AtIndex`
**目标:** 根据密度、速度和归一化二阶矩，重构指定方向 `i` 的 D2Q9 分布函数 `f_i`。

### 算法原理

分布函数通过 Hermite 多项式展开重构。参考 [testMrLBM2D.cpp](file:///d:/Code/CG/Phy/Homed2%20copy/src/testMrLBM2D.cpp#L395-L457) 中的 `ReconstructDistribution` 函数。

输入参数（**注意**：参数顺序为 `pixx, pixy, piyy`，与 fMom 的存储偏移 3/4/5 → `pixx, piyy, pixy` 顺序不同）：

- `rho` — 密度
- `ux`, `uy` — 速度
- `pixx` — 归一化二阶矩（fMom 偏移 3）
- `pixy` — 归一化二阶矩（fMom 偏移 5）
- `piyy` — 归一化二阶矩（fMom 偏移 4）

### 具体步骤

1. **计算 Hermite 展开系数（原始矩）：**

```cpp
REAL a0  = rho;
REAL ax  = rho * ux;
REAL ay  = rho * uy;
REAL axx = rho * pixx;
REAL ayy = rho * piyy;
REAL axy = rho * pixy;
REAL axxy = -2.0f * rho * uy * ux * ux + 2.0f * axy * ux + axx * uy;
REAL axyy = -2.0f * rho * ux * uy * uy + 2.0f * axy * uy + ayy * ux;
```

其中 `axx = rho * pixx = raw_pixx - rho * cs^2` 是二阶 Hermite 系数；`axxy`、`axyy` 为三阶系数，通过低阶系数的递推关系得出。

1. **按方向** **`i`** **计算多项式值：**

| i | 多项式                                                          |
| - | ------------------------------------------------------------ |
| 0 | `a0 - 1.5*axx - 1.5*ayy`                                     |
| 1 | `a0 + 3*ax + 3*axx - 4.5*axyy - 1.5*ayy`                     |
| 2 | `a0 - 1.5*axx - 4.5*axxy + 3*ay + 3*ayy`                     |
| 3 | `a0 - 3*ax + 3*axx + 4.5*axyy - 1.5*ayy`                     |
| 4 | `a0 - 1.5*axx + 4.5*axxy - 3*ay + 3*ayy`                     |
| 5 | `a0 + 3*ax + 3*axx + 9*axy + 9*axxy + 9*axyy + 3*ay + 3*ayy` |
| 6 | `a0 - 3*ax + 3*axx - 9*axy + 9*axxy - 9*axyy + 3*ay + 3*ayy` |
| 7 | `a0 - 3*ax + 3*axx + 9*axy - 9*axxy - 9*axyy - 3*ay + 3*ayy` |
| 8 | `a0 + 3*ax + 3*axx - 9*axy - 9*axxy + 9*axyy - 3*ay + 3*ayy` |

1. **输出（注意非负截断，防止浮点舍入产生负值）：**

```cpp
f_out = w2d_gpu[i] * polynomial;
if (f_out < 0.0f) f_out = 0.0f;
```

## 实现思路 P1-B

**文件:** `inc/2D/gpu/mrUtilFuncGpu2D.h`
**函数:** `mrUtilFuncGpu2D::mlGetPIAfterCollision`
**目标:** 对三个**原始**二阶矩（非归一化）原地执行 BGK 碰撞，并加入体力修正。

### 算法原理

输入参数：

- `R` — 密度 rho
- `U`, `V` — 宏观速度（已含体力半时间步修正，见 P1-C）
- `Fx`, `Fy` — 体力分量
- `omega` — 松弛参数 (omega = 1/tau)
- `pixx`, `piyy`, `pixy` — 原始二阶矩（输入/输出）

其中 `pixx = sum(f_i * ex_i^2)`，`piyy = sum(f_i * ey_i^2)`，`pixy = sum(f_i * ex_i * ey_i)`。

### 具体步骤

1. **计算平衡态原始二阶矩**（使用体力修正后的速度，cs^2 = 1/3）：

```cpp
REAL pixx_eq = R * (U * U + cs2);
REAL piyy_eq = R * (V * V + cs2);
REAL pixy_eq = R * U * V;
```

1. **BGK 碰撞：**

```cpp
pixx -= omega * (pixx - pixx_eq);
piyy -= omega * (piyy - piyy_eq);
pixy -= omega * (pixy - pixy_eq);
```

1. **体力修正**（Guo 格式，对二阶矩的修正项）：

```cpp
REAL forceFactor = 1.0f - 0.5f * omega;
pixx += forceFactor * 2.0f * U * Fx;
piyy += forceFactor * 2.0f * V * Fy;
pixy += forceFactor * (U * Fy + V * Fx);
```

## 实现思路 P1-C

**文件:** `inc/2D/gpu/mrLbmSolverGpu2D.cu`
**Kernel:** `mrSolver2DKernel`
**目标:** 对流体格点实现一次完整的 LBM 更新：pull streaming → 宏观量恢复 → 二阶矩碰撞 → 归一化 → 写回 `fMomPost`。

### 具体步骤

1. **线程映射：**

```cpp
int x = blockIdx.x * blockDim.x + threadIdx.x;
int y = blockIdx.y * blockDim.y + threadIdx.y;
if (x >= sample_x || y >= sample_y) return;

int index = y * sample_x + x;
MLLATTICENODE_FLAG flag = mlflow[0].flag[index];
if (flag != ML_FLUID) return;  // 只处理流体格点
```

1. **Pull streaming：** 对每个方向 `i = 0..8`，从上游邻居 `(x - ex[i], y - ey[i])` 的 `fMom` 重构 `f_i`。

   注意：邻居可能是边界格点（INLET/OUTLET/WALL），其 fMom 已由 `RefreshDemoCaseBoundaries` 预先填写好。这是边界条件向流体内部传播的关键——pull streaming 天然地将边界信息带入流体计算。

```cpp
// 注意：这两个辅助函数是非静态成员函数，必须通过对象实例调用
mrUtilFuncGpu2D util;
REAL f[9];
for (int i = 0; i < 9; i++) {
    int nx = x - (int)ex2d_gpu[i];  // 拉取方向：粒子来自上游
    int ny = y - (int)ey2d_gpu[i];
    // 越界 clamp（安全措施，对域内流体格点理论上不会越界）
    if (nx < 0) nx = 0; if (nx >= sample_x) nx = sample_x - 1;
    if (ny < 0) ny = 0; if (ny >= sample_y) ny = sample_y - 1;
    int neighborIdx = ny * sample_x + nx;
    REAL* neighborMom = &mlflow[0].fMom[neighborIdx * 6];
    // 注意参数顺序：pixx(offset 3), pixy(offset 5), piyy(offset 4)
    util.mlCalDistributionD2Q9AtIndex(
        neighborMom[0], neighborMom[1], neighborMom[2],
        neighborMom[3], neighborMom[5], neighborMom[4],
        i, f[i]);
}
```

1. **宏观量恢复**（含体力半时间步修正）：

```cpp
REAL rho = 0.0f;
REAL ux_times_rho = 0.0f, uy_times_rho = 0.0f;
REAL pixx_raw = 0.0f, piyy_raw = 0.0f, pixy_raw = 0.0f;
for (int i = 0; i < 9; i++) {
    rho += f[i];
    ux_times_rho += f[i] * ex2d_gpu[i];
    uy_times_rho += f[i] * ey2d_gpu[i];
    pixx_raw += f[i] * ex2d_gpu[i] * ex2d_gpu[i];
    piyy_raw += f[i] * ey2d_gpu[i] * ey2d_gpu[i];
    pixy_raw += f[i] * ex2d_gpu[i] * ey2d_gpu[i];
}

// 体力修正速度（Guo 半时间步格式）
REAL Fx = mlflow[0].forcex[index];
REAL Fy = mlflow[0].forcey[index];
REAL ux = (ux_times_rho + 0.5f * Fx) / rho;
REAL uy = (uy_times_rho + 0.5f * Fy) / rho;
```

1. **计算 omega 和碰撞：**

```cpp
REAL vis = mlflow[0].vis_shear;
REAL tau = vis / cs2 + 0.5f;   // 由 ν = (2τ-1)/6 和 cs²=1/3 推导：τ = 3ν + 0.5
REAL omega = 1.0f / tau;

// 继续使用步骤 2 中创建的 util 对象实例调用非静态成员函数
util.mlGetPIAfterCollision(
    rho, ux, uy, Fx, Fy, omega, pixx_raw, piyy_raw, pixy_raw);
```

1. **归一化二阶矩并写回** **`fMomPost`：**

```cpp
REAL* post = &mlflow[0].fMomPost[index * 6];
post[0] = rho;
post[1] = ux;
post[2] = uy;
post[3] = pixx_raw / rho - cs2;  // 归一化 pixx
post[4] = piyy_raw / rho - cs2;  // 归一化 piyy
post[5] = pixy_raw / rho;        // 归一化 pixy
```

> 注意：`mrSolver2D_step2Kernel` 已实现，会自动交换 `fMom` 和 `fMomPost` 指针，无需手动处理。

### 上下文

函数入口已提供：

1. **重新分类所有格点：**

```cpp
        int idx = y * nx + x;

        newFlags[idx] = isSolid ? ML_SOLID : baseFlag;
    }
}
```

1. **记录状态变更的格点（仅追踪与 ML\_SOLID 之间的互相转换）：**

```cpp
for (int idx = 0; idx < count; idx++) {
    bool wasSolid = (oldFlags[idx] == ML_SOLID);
    bool isSolid = (newFlags[idx] == ML_SOLID);
    if (wasSolid && !isSolid)
        releasedCells.push_back(idx);  // 固体 → 流体/边界
    else if (!wasSolid && isSolid)
        solidCells.push_back(idx);     // 流体/边界 → 固体
}
```

1. **重建新释放流体格点的矩：**

对每个 `releasedCells` 中的格点，调用 `AverageNeighborMoments(flow, x, y, oldFlags, newFlags, true, result)`。参数 `true` 表示仅平均那些"原本就是流体且在移动前后始终是流体"的邻居，这样获得的矩最可靠。若成功获得邻域平均矩，则用 `WriteMoments2D` 写入。

> 注意：释放的格点可能在下一帧变成边界格点（INLET/OUTLET），此时 `RefreshDemoCaseBoundaries` 会将其矩覆盖为正确的边界值。此处用邻居平均仅是临时合理初值。

`WriteBoundaryMoments` 会保留邻居的非平衡应力，同时将速度替换为壁面速度 `wallUx, wallUy`。壁面速度由调用方传入（即 `moveX/stepsPerFrame` 和 `moveY/stepsPerFrame`）。

1. **更新全局状态：**

```cpp
// 将所有 solidCells、releasedCells 合并到 touchedCells
touchedCells.insert(touchedCells.end(), solidCells.begin(), solidCells.end());
touchedCells.insert(touchedCells.end(), releasedCells.begin(), releasedCells.end());

// 更新 obstacle pose
obstacleX = newX;
obstacleY = newY;
obstacleVelocityX = wallUx;
obstacleVelocityY = wallUy;

// 更新 host flag 数组
for (int idx = 0; idx < count; idx++)
    flow->flag[idx] = newFlags[idx];

flagsChanged = true;
```

- `y == 0` → `ML_INLET`（底部全宽入口）

```cpp
if (definition.id == DemoCaseId::KarmanVortex) {

```

- `y == 0`：
  - `IsJetInlet(definition, x)` → `ML_INLET`（居中喷口）

- `x == definition.nx - 1` → `ML_WALL_RIGHT`
- `y == definition.ny - 1` → `ML_OUTLET`（顶部出口）
- 其余 → `ML_FLUID`

```cpp
if (definition.id == DemoCaseId::JetFlow) {

    if (x == definition.nx - 1) return ML_WALL_RIGHT;
    if (y == definition.ny - 1) return ML_OUTLET;
    return ML_FLUID;
}
```

## 实现思路 P2-P3-C

**文件:** `src/LbmCases2D.cpp`
**函数:** `RefreshDemoCaseBoundaries`
**目标:** 逐帧刷新外层边界矩。入口使用规定速度，出口复制相邻内部速度，固壁用零速度，从相邻内部格点外推非平衡应力。

### 具体步骤

1. **计算 Karman 横向扰动**（仅在 Karman 算例中，扰动加在 x 方向——主流方向为 y，横向扰动帮助触发涡街）：

```cpp
REAL perturbation = 0.0f;
if (definition.id == DemoCaseId::KarmanVortex) {
    perturbation = definition.inletPerturbationAmplitude *
        sinf(2.0f * 3.14159265358979323846f * (REAL)iteration /
             (REAL)definition.inletPerturbationPeriod);
}
```

1. 遍历边界行/列，对每个边界格点找到相邻内部格点，确定目标速度，调用 `WriteBoundaryMoments`：

```cpp
// 底部边界 (y = 0) —— 处理所有底部格点，包括角点
for (int x = 0; x < definition.nx; x++) {
    int idx = 0 * definition.nx + x;
    int neighborIdx = 1 * definition.nx + x;  // y=1 的相邻内部
    REAL ux = 0.0f, uy = 0.0f;

    if (flow->flag[idx] == ML_INLET) {
        ux = definition.inletUx + perturbation;  // 入口 + 横向扰动
        uy = definition.inletUy;
    }
    // ML_WALL_DOWN 保持 ux=uy=0
    WriteBoundaryMoments(flow, idx, neighborIdx, ux, uy);
}

// 顶部边界 (y = ny-1)：全部为 ML_OUTLET，复制邻居速度
for (int x = 0; x < definition.nx; x++) {
    int idx = (definition.ny - 1) * definition.nx + x;
    int neighborIdx = (definition.ny - 2) * definition.nx + x;
    // 出口：复制紧邻内部格点的速度
    WriteBoundaryMoments(flow, idx, neighborIdx,
        flow->fMom[neighborIdx * 6 + 1],
        flow->fMom[neighborIdx * 6 + 2]);
}

// 左侧边界 (x = 0)，排除顶部和底部角点（已由上下边界循环处理）
for (int y = 1; y < definition.ny - 1; y++) {
    int idx = y * definition.nx + 0;
    int neighborIdx = y * definition.nx + 1;
    REAL ux = 0.0f, uy = 0.0f;
    if (flow->flag[idx] == ML_OUTLET) {
        // Karman: 开放出口，复制内部速度
        ux = flow->fMom[neighborIdx * 6 + 1];
        uy = flow->fMom[neighborIdx * 6 + 2];
    }
    // Jet Flow: ML_WALL_LEFT，保持 ux=uy=0
    WriteBoundaryMoments(flow, idx, neighborIdx, ux, uy);
}

// 右侧边界 (x = nx-1)，排除顶部和底部角点
for (int y = 1; y < definition.ny - 1; y++) {
    int idx = y * definition.nx + (definition.nx - 1);
    int neighborIdx = y * definition.nx + (definition.nx - 2);
    REAL ux = 0.0f, uy = 0.0f;
    if (flow->flag[idx] == ML_OUTLET) {
        // Karman: 开放出口，复制内部速度
        ux = flow->fMom[neighborIdx * 6 + 1];
        uy = flow->fMom[neighborIdx * 6 + 2];
    }
    // Jet Flow: ML_WALL_RIGHT，保持 ux=uy=0
    WriteBoundaryMoments(flow, idx, neighborIdx, ux, uy);
}
```

### 边界速度规则总结

| 边界标记                | 目标速度                                       |
| ------------------- | ------------------------------------------ |
| `ML_INLET` (Karman) | `(perturbation, inletUy)` —— 扰动只加在 x（横向）分量 |
| `ML_INLET` (Jet)    | `(0, inletUy)`                             |
| `ML_OUTLET`         | 复制相邻内部格点速度                                 |
| `ML_WALL_*`         | `(0, 0)`                                   |

> 注意：`WriteBoundaryMoments` 会保留邻居的非平衡应力分量，仅替换速度为边界目标速度。角点（如 (0,0)、0,ny-1) 由上下边界循环统一覆盖，左右边界循环的 y 范围 `[1, ny-2]` 可以安全地避免重复处理。
