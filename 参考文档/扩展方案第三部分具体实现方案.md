## 1. 总体设计

### 1.1 交互状态机

```
按住 Ctrl（WM_KEYDOWN VK_CONTROL）→ ctrlHeld = true
├─ 放大镜：跟随光标（每帧 DrawMagnifier，以 mouseFieldX/Y 为中心）
├─ Ctrl + 左键（WM_LBUTTONDOWN）→ debugCellX/Y = round(mouseFieldX/Y)（clamp 到场内）
│   └─ DrawCellDebugOverlay：格点高亮框 + 数据面板
└─ 松开 Ctrl（WM_KEYUP VK_CONTROL）→ ctrlHeld = false，debugCellX/Y = -1
```

- Ctrl 按住期间：**不进入物体拖动 / 力源工具**（`WM_LBUTTONDOWN` 的 Ctrl 分支先于拾取返回；`ApplyMouseEffects` 也加了 `!ctrlHeld` 门控，双保险）。
- 鼠标在 UI 面板上时不显示放大镜（面板下方格点坐标无意义）。
- 失焦（`WM_KILLFOCUS`）时强制退出调试模式，防止 Ctrl 卡住。

## 2. FPS / 每步耗时 HUD（评估文档 §9 附加项 1）

### 2.1 显示内容与位置

- **位置**：画面（流场区域 `layout.field`）**右上角**，灰底白字。
- **内容**（4 行）：
  ```
  FPS: 60.0
  frame: 16.67 ms
  sim: 12.30 ms
  LBM: 0.82 ms/step
  ```
  - `FPS`：渲染帧率（0.5s 滚动窗口计数）。
  - `frame`：每 UI 帧耗时 = 1000 / FPS。
  - `sim`：每 UI 帧**仿真**耗时（`AdvanceObstacles + Step`），QPC 测量、EMA 平滑。
  - `LBM`：`sim / stepsPerFrame`（单 LBM 步平均耗时，`stepsPerFrame` 取 max(1, 当前值)）。

### 2.2 实现要点

1. **计时成员**（模块级，[L1704-L1711](file:///d:/Code/CG/Phy/home2d/src/testMrLBM2D.cpp#L1704-L1711)）：
   ```cpp
   LARGE_INTEGER gPerfFrequency = {};  // main() 里 QueryPerformanceFrequency 初始化
   double gSimMsSmoothed = 0.0;        // 仿真耗时 EMA 平滑值
   DWORD gFpsWindowStart = 0;          // FPS 窗口起点（GetTickCount）
   int gFpsFrameCount = 0;
   float gFps = 0.0f;
   ```
2. **FPS 计数**（`Render` 内，[L3037-L3049](file:///d:/Code/CG/Phy/home2d/src/testMrLBM2D.cpp#L3037-L3049)）：每帧 `gFpsFrameCount++`，累计 ≥500ms 时 `FPS = 帧数 × 1000 / 经过毫秒`，然后重置窗口。窗口化计数比逐帧 EMA 更稳。
3. **仿真耗时**（`AdvanceOneUiFrame` 内，[L3088-L3103](file:///d:/Code/CG/Phy/home2d/src/testMrLBM2D.cpp#L3088-L3103)）：
   ```cpp
   LARGE_INTEGER start; QueryPerformanceCounter(&start);
   gApp.AdvanceObstacles(); gApp.Step();
   LARGE_INTEGER end; QueryPerformanceCounter(&end);
   const double ms = (end.QuadPart - start.QuadPart) * 1000.0 / gPerfFrequency.QuadPart;
   gSimMsSmoothed = gSimMsSmoothed * 0.90 + ms * 0.10;   // EMA
   ```
   无论定时器（`WM_TIMER`）还是 `S` 键单步都会走 `AdvanceOneUiFrame`，统计天然覆盖两种路径。
4. **绘制**（`DrawFpsOverlay`，[L2459-L2496](file:///d:/Code/CG/Phy/home2d/src/testMrLBM2D.cpp#L2459-L2496)）：
   - 宽度 = 最长行字符数 × `kTextCharWidth`（9px，Consolas 16px 估算）+ 左右 padding；
   - 高度 = 行数 × `kTextLineHeight`（18px）+ 上下 padding；
   - 灰底：`DrawSolidRect(bg, 0.20f, 0.22f, 0.25f, 0.85f)`（半透明，需临时 `glEnable(GL_BLEND)`）；
   - 白字：`glColor3f(1,1,1)` + `DrawText` 逐行绘制。

> 说明：色条在右下角、FPS HUD 在右上角、放大镜在左下角、调试面板在选中格点附近（可移动）——四个浮层互不冲突。

## 5. 局部放大镜（评估文档 §6.2-5A，推荐方案）

### 5.1 原理

不做任何新数据：**只改 `glTexCoord` 子区域 + 一个放大 quad**，把 `gFieldTexture` 上以光标为中心的 ±8 格区域画到流场左下角。

### 5.2 坐标换算（关键，与 DrawField 纹理约定一致）

`DrawField` 把纹理 v=0 放在 `field.bottom`（格点 y=0 在底部）、v=1 放在 `field.top`。因此：

```
u = gx / (nx-1)     （格点 x → 纹理 u，左→右）
v = gy / (ny-1)     （格点 y → 纹理 v，下→上）
```

放大镜区域（中心 `centerX/centerY = clamp(mouseFieldX/Y, 0, nx-1)`，半径 `half = kMagnifierRadius = 8`）：

```cpp
const float u0 = clamp((centerX - half) * invNx, 0, 1);
const float u1 = clamp((centerX + half) * invNx, 0, 1);
const float v0 = clamp((centerY - half) * invNy, 0, 1);
const float v1 = clamp((centerY + half) * invNy, 0, 1);
```

### 5.3 放大比例与摆放

```cpp
const float regionW = (u1 - u0) * field.Width();   // 区域在原流场中的屏幕宽
const float regionH = (v1 - v0) * field.Height();
const float zoom = clamp(min(kMagnifierMaxSize / regionW,
                             kMagnifierMaxSize / regionH), 1.0f, ...);  // ≥1 才算放大
const float mw = regionW * zoom, mh = regionH * zoom;
const float x0 = field.left + 10.0f;               // 左下角
const float y0 = field.bottom - 10.0f - mh;
```

- **等比缩放**：`zoom` 同时约束两个方向，放大后的格点形状与原流场一致（不畸变）。
- 绘制纹理 quad 时顶点顺序：左下 `(u0,v0)` → 右下 `(u1,v0)` → 右上 `(u1,v1)` → 左上 `(u0,v1)`，与 `DrawField` 同约定。

### 5.4 附加可视化（画在放大镜上）

1. **网格线**：对区域内的整数格线 `gx/gy`（`ceil(center-half) … floor(center+half)`），
   ```
   sx = x0 + (u(gx) - u0) / (u1 - u0) * mw
   sy = y0 + (v(gy) - v0) / (v1 - v0) * mh
   ```
   半透明灰色（`glColor4f(0.55,0.60,0.65,0.45)`），便于观察格点结构。
2. **光标所在格点高亮框**：`gxc = floor(centerX)`（clamp 到 `[0, nx-2]`），黄绿色 `GL_LINE_LOOP`。
3. **外边框**（亮灰）+ **放大倍数标签** `"x%.1f"`（`DrawText` 画在放大镜上方）。

> 半透明绘制统一用 `glEnable(GL_BLEND); glBlendFunc(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA);` 包裹，结束即关闭（`DrawField/DrawBodies` 是纯色不透明绘制，不依赖混合状态）。

### 6.1 选中格点高亮框

```cpp
const RectF cell = CellScreenRect(field, cx, cy);   // 格点 (cx,cy) 的屏幕矩形
```

### 6.2 调试面板内容（14 行）

| 行 | 内容 | 数据来源 |
| --- | --- | --- |
| 1 | `cell: (x, y)` | `debugCellX/Y`（**格点坐标**） |
| 2 | `flag: FLUID/SOLID/INLET/…` | `flow->flag[idx]` → `FlagName`（[L2190-L2216](file:///d:/Code/CG/Phy/home2d/src/testMrLBM2D.cpp#L2190-L2216)） |
| 3~8 | `rho / ux / uy / sxx / syy / sxy` | `fMom[idx*6+0..5]`（`ReadMoments`） |
| 9~10 | `fx / fy` | `flow->forcex/forcey[idx]`（§4 已回 host） |
| 11 | `Re: xxx.x` | `GetDemoCaseReynoldsNumber(definition)`（**宏观参数**） |
| 12 | `iter: n` | `gApp.iteration` |
| 13 | `steps/frame: n` | `gApp.stepsPerFrame` |
| 14 | `vis: 0.0080` | `definition.viscosity` |

> 格点内全部数据 = flag + fMom 六个宏观矩 + force 两分量，全部展示；宏观参数取 Re/iter/stepsPerFrame/viscosity。如需扩展（如物体受力、最大速度），在 `lines` 追加一行即可。

### 6.3 面板摆放（避开格点高亮框）

- 默认放格点**右上方**（`px = cell.right + 10`，`py = cell.top - 10`）；
- 放不下（超出 field 右缘）则换到格点**左下方**；
- 最后对 `px/py` 整体 clamp 到 `field ± 4` 内，保证面板永不越界。
- 面板尺寸 = 最长行 × `kTextCharWidth` + padding；高度 = 行数 × `kTextLineHeight` + padding。

### 6.4 样式

- 底色：半透明近黑 `DrawSolidRect(bg, 0.08f, 0.09f, 0.12f, 0.82f)`（`GL_BLEND` 临时开启）。
- 文字：`glColor3f(1,1,1)` + `DrawText` 逐行（复用位图字体，无新字体）。

## 7. 渲染挂点顺序（Render）

```
glClear → BeginScreenCoordinates
DrawField(layout.field)          // 流场纹理
DrawBodies(layout.field)         // 物体轮廓
DrawDebugOverlay(layout)         // 功能 5：Ctrl 门控 → 放大镜 + 调试面板（§5/§6）
RebuildLegendTexture (Colorful 时)
DrawLegendOverlay(field)         // 色条（右下角）
DrawFpsOverlay(field)            // FPS HUD（右上角，§2）
ImGui NewFrame / BuildAppUi / Render
```

## 8. 交互与健壮性清单

1. **Ctrl 双保险**：`WM_LBUTTONDOWN` 的 Ctrl 分支 + `ApplyMouseEffects` 的 `!ctrlHeld` 门控，Ctrl 模式绝不拖物体/施力。
2. **松开即消失**：`WM_KEYUP` 清 `ctrlHeld` 与 `debugCellX/Y`；`WM_KILLFOCUS` 兜底复位。
3. **面板豁免**：放大镜在鼠标位于 UI 面板（`IsOverUiPanel`）或 ImGui 捕获鼠标时跳过，防止面板下方无效格点坐标造成边缘吸附。
4. **坐标 clamp**：调试格点四舍五入后 clamp 到 `[0, nx-1]×[0, ny-1]`；放大镜中心 clamp 到 `[0, nx-1]`。
5. **纹理约定一致**：放大镜纹理子区域与 `DrawField` 同为 v=0 在底部；网格线/高亮框用同一映射换算，避免错位。
6. **混合状态收放**：半透明绘制前后成对 `glEnable(GL_BLEND)` / `glDisable(GL_BLEND)`，不影响后续 ImGui 与交换缓冲。
7. **性能**：放大镜纯渲染层（一个 quad + 约 34 条网格线），调试面板每帧只读 1 个格点的数据 + 14 行文本，开销可忽略；force D2H 拷贝 ~147KB/帧可忽略。
8. **数值守卫**：调试面板读 `fMom` 前无需额外判断——`ReadMoments` 原样读取，即使偶发 NaN 也只影响显示（不改动流场数据）。
9. **不触碰 `.cu`**：kernel 零改动；force 回 host 只是多一次 `_MLCuMemcpy`。
10. **失焦复位**：`WM_KILLFOCUS` 一并清 `ctrlHeld`（§3.1），避免调试模式"卡住"。

## 9. 验收清单
